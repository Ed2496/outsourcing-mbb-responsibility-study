2. **閉環四環**：公告 ✓ → 統計 ✗ → 查核 ✗ → 處分 ✗——監督斷在第二環之後
3. **S1–S8 階段模型**（由陳水扁案 21 年、拉法葉案 35 年拆解）：潛伏進行 → 爆發 → 高峰對質 → 制度回應 → 疲勞靜默 → 切割處分 → 敘事逆轉結案 → 長程遺留；卸責槽活動期集中在 S4→S7
