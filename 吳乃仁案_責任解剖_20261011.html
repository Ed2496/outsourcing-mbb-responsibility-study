吳乃仁案：從「賤賣」到「不追賠」的責任解剖

Root cause 是人，不是結構 2002 賤賣國土、2026 撤回追償，兩頭掛在同一條任命鏈上。本解剖不問站哪隊，只問：是不是事實、能不能釘到具名的人。

前民進黨秘書長、台糖前董事長吳乃仁，因台糖土地賤賣案賠償約 1.7 億元未清償遭管收；台糖撤回聲請，12 天即獲釋。背信罪 2014 年台中高分院判 9 月定讞。

一、分辨：管收是逼債的開關，不是犯罪的刑期

誤解：把管收當成刑期

關——ON = 施壓，OFF = 撤回放人
台糖說法：管收目的是逼債務人出面協商，非處罰。律師承諾 7/20 前提清償計畫 →「目的達成」故撤回。開關一開一關之間，人就進出。

二、新階段的病理：面帳全合法，裡帳在抽血

面帳
合法 · 程序 · 敘事
裡帳
得利 · 意圖 · 掏空
資本主義新階段：所有動作都設計成合法。掏空不在面帳，在面帳與裡帳的落差裡。抓縫，就是 MBB 鑑識的活。

三、骨·核心：同一條任命鏈，綁著兩頭

總統→ 行政院 核定→ 經濟部 報請→ 台糖董座
2002 吳乃仁
賤賣 · 背信定讞｜故意作為 · 閉環 ✔
2026 台糖董座
撤回 · 故意不作為｜授意待證 ？
台糖 100% 官股，董座由「行政院核定 → 經濟部報請 → 董事會選任」產生。2002（陳水扁）與 2026（賴清德）是同一條 DPP 行政權任命鏈——這不是觀點，是遴聘要點白紙黑字。
查證註記（語料自載）：現任董座確認為吳明昌（2024/11 就任）；語料來源所寫「許裕興」查無佐證，待驗。

四、手法：三段各自合法，合起來沒人負責

台糖
應庭訊·非主動→ 經濟部
未通報·尊重專業→ 法院
依聲請·依撤回＝ 誰放的人？
把一個政治後果，拆成三段各自合法的程序動作，主詞在傳遞中被蒸發——跟「把『我』塗掉、話就變真理」是同一手，只是搬到組織層。這是責任洗白手術。

五、破「不做不錯」：有義務者的「不做」，就是他的錯

無義務者不做 ＝ 中性 ✔
一般情形下，不做不錯成立。
全民資產：有義務者不做 ＝ 違反
義務 ＋ 明知 ＋ 選擇不為 ＝ 故意的不作為。撤回聲請那張狀，就是「選擇不為」的落款。

六、8D：填「結構」進 root cause，就是簽下貳過同意書

Root Cause：「結構／新階段」
永遠成立 → 無解 → 保證貳過。
Root Cause：具名的人 ＋ 故意
釘死 → 可閉環。
結構永遠在，填進去等於宣布無解。Root cause 必須是人：有目的、故意為之——2002 吳乃仁（故意作為，定讞）；2026 台糖董座（故意不作為，義務＋明知＋選擇皆有跡）。就算上游授意永遠查不到，董座的不作為責任已獨立成立。

七、不貳過

在「不做不錯」的時代唯一能不貳過的，是把作為義務釘進 root cause
讓「不做」重新變成一個有主詞、有錯、有人負責的動作。這一釘下去，CAPA 才有對象，8D 才修得動。

附錄：制度裂縫報告（吳乃仁獲釋事件）——八頁語料之首頁

「二十年的債，十二天的關，一天的放。」
2002 土地政策變更 → 2014 背信罪定讞 → 2026/6/11 管收裁定 → 6/22 撤回釋放。管收變成協商邀請函：法律定位是「促使履行」，實際功能只換得律師一句「我會談」。

一把可以隨時收回的刀

依《強制執行法》第 22 條之 4，債權人撤回聲請後，法院應即釋放被管收人，無實質審查權——「台糖可以隨時喊停，法院只能照做。」

公司法人 vs 全民資產守門人：台糖的雙重身分解離

台糖 100% 國家持股，資產屬全民；但撤回 1.7 億債務人的管收聲請，只需董事長與律師決定，無需上級核准——「台糖以公司名義撤回，全民卻沒有否決權。」

二十年追不到錢的設計漏洞

刑事定罪與民事執行之間的斷層：2014 定讞後，民事強制執行至 2026 年僅追回 500–700 萬元，吳乃仁名下幾乎無可供查扣資產。「刑事定了罪，民事追不到錢，中間二十年無人看守。」

五種人，五種真相——同一事件，五種視角，五個盲點

角色看見盲點
藍白立委政治介入忽略制度缺陷
輿論公平質疑情緒優先
法院程序合法不問工具化
台糖專業判斷不問監督真空
吳乃仁協商解決不問多年不還
「有人看見陰謀，有人看見程序，沒有人看見制度。」五種視角都正確，也都只看見自己想看的。

事件會重演的三個未解矛盾

① 管收目的定義權——誰說了算？② 國營決策邊界——誰能否決？③ 財產監控真空——錢去哪了？三線匯聚，無解。
「問誰施壓，不如問制度為何給施壓留空間。」——管收成為協商籌碼、國營事業重大訴訟無監督、債務人財產長期監控失靈，三個矛盾從未被修法補強。
這面照妖鏡，照的是制度不是人
強制執行法的工具化、國營事業治理的監督真空、民事追償與刑事定罪的時間斷層——這些才是鏡中真實的影像。「吳乃仁會離開，但制度的裂縫會留下。」
